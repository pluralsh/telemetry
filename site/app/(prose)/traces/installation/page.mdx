This guide assumes the operator is already installed; see [Installation](/installation/). Examples use the `telemetry` Kubernetes namespace and an S3 bucket named `acme-telemetry`.

## Choose a mode

| Mode | Pods | Storage | Use it for |
| --- | --- | --- | --- |
| [Standalone](/traces/installation/standalone/) | One pod that ingests and queries | A volume, or a bucket | Development and small clusters |
| [Reader/writer split](/traces/installation/read-write/) | One writer, autoscaled readers | A shared bucket | Heavy query load on modest ingest |
| [Sharded](/traces/installation/sharded/) | Several writers, a reader group per shard | A shared bucket | Ingest beyond one writer |

The split and sharded modes are the same `Sharded` resource with one writer or several, so a split deployment grows into a sharded one by raising `spec.writer.replicas`.

## Grant S3 access

Skip this for a standalone database on a volume. Otherwise Traces authenticates to S3 with [EKS Pod Identity](https://docs.aws.amazon.com/eks/latest/userguide/pod-identities.html). The operator creates a ServiceAccount named after the database, `traces`, so associate an IAM role with it:

<PodIdentitySetup product="traces" />

The role's trust policy must allow `pods.eks.amazonaws.com` to call `sts:AssumeRole` and `sts:TagSession`. No keys go in the spec.

## Access

Traces serves a tenant namespace only once it has credentials. Each `NamespaceAuthentication` creates its namespace if needed and grants one username `read` or `write`. Create the password Secrets first:

<PasswordSecrets product="traces" />

Then grant a writer for the collector and a reader for Grafana:

<AccessSpec product="traces" />

Clients send these as HTTP basic auth.

## Connect your tools

Writers serve ingest routes and readers serve queries. In the split and sharded modes, inside the cluster:

A standalone database serves both from the one `traces` Service. Any writer accepts any span and forwards each trace to its shard's owner, so the plain `traces-writer` Service is all a client needs. For an OTel Collector and Grafana:
